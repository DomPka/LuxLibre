# Using the names LuxLibre and FlashKa

The licences ([LICENSING.md](LICENSING.md)) let anyone use, change and sell LuxLibre. The
**names** are a different matter: people should be able to trust that a light called
"LuxLibre" or "FlashKa" really follows the project's design rules and runs its firmware. This
policy says how to use the names. The project does not currently hold registered trademarks;
this is a statement of how the names are meant to be used, in the spirit of the name policies
of many open-source projects.

## Always fine

- Saying that a product **runs LuxLibre firmware**, is **based on LuxLibre** or is **based on the
  FlashKa design**, when that is true.
- "LuxLibre compatible" for boards that run the unmodified LuxLibre firmware with a board header
  you publish.
- Using the names in articles, reviews, courses, videos, forks on code-hosting sites and
  conversations about the project.

## Please ask first

- Naming a product, company or service **"LuxLibre"** or **"FlashKa"**, or with a name that is
  easily confused with them (for example "LuxLibre Pro" for your own light).
- Calling a light "FlashKa" when its hardware or firmware has been changed in ways that affect
  safety (laser class, thermal limits, protection circuits).
- Using the names in a way that suggests the project endorses your product.

Open an issue in the project's repository to ask; there is no fee.

## Never

- Using the names for lights that do not meet the project's safety rules
  ([docs/design-rules.md](docs/design-rules.md), especially the BAT, CHG, THM and LAS rules).
- Using the names for products with a laser above Class 2.

## The words themselves

*LuxLibre* combines Latin *lux* (light) with *libre* (free, as in freedom). *FlashKa* is the
name of the keychain reference design.
