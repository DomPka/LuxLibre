Reference design

FlashKa Keychain v0.7

A keychain flashlight with a laser pointer, USB-C charging and Bluetooth. In presenter mode it becomes a Bluetooth keyboard that turns your slides. Version 0.7 is the 1000 lm FlashKa: a TIR optic throws the beam about 160 m (simulated), one 14500 cell powers it, the body is a faceted octagon, and the three keys sit on the centre line, a clear main key with a glowing ring between two rubber keys.

Designed and checked by software; the light figures are simulated. The first one has not been built yet.

Open the control app

Uses Web Bluetooth: Chrome or Edge on Android, Windows, macOS and ChromeOS (on Linux, Chrome may need the Web Bluetooth flag); on iPhone and iPad the free Bluefy browser.

Install the firmware

Uses Web Serial: Chrome or Edge on a computer, with a USB-C data cable. Phones and tablets cannot do this. The installer asks whether you have a FlashKa v0.7 or v0.6.

Try the demo. No FlashKa yet? Open the control app and press Try demo mode: a simulated light runs inside the page, in any browser.

Both pages run entirely in your browser: nothing is uploaded.
