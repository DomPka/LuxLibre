# FlashKa v0.7: drawings and CAD

The files of the FlashKa v0.7 housing, made from the design scripts in [../tools/](../tools/) (nothing is drawn by hand). STEP files open in FreeCAD, Fusion, Onshape or any CAD program; DXF in LibreCAD, QCAD or any CAD program; PDF and PNG are for reading. The design page explains every part: [FlashKa v0.7](../README.md).

## Data

| File | What it is |
|---|---|
| [`drawings_dimension_table.txt`](drawings_dimension_table.txt) | every number on the drawings against its parameter, and the ray-probe cross-check |
| [`housing_interface.json`](housing_interface.json) | the contract between the housing and the boards: sizes, positions, walls |
| [`key_mould_checks.json`](key_mould_checks.json) |  |
| [`pcb_placement.json`](pcb_placement.json) | where the main board's parts sit, as the housing checks them |
| [`pcb_placement_keys.json`](pcb_placement_keys.json) | the same for the key board |

The drawings are made by [tools/housing/drawings.py](../tools/housing/drawings.py); the parts to order are in [order_files/](../order_files/README.txt).
