Install the flashlight firmware

This page puts the FlashKa firmware onto your flashlight through its USB-C port. It takes about a minute. Nothing is uploaded anywhere: everything happens inside this browser tab.

  • A computer (Windows, Mac, Linux or Chromebook) with Chrome or Edge. Phones and tablets cannot do this.
  • A USB-C cable that carries data, not only power.
  1. 1

    Plug in the flashlight

    Plug the flashlight into your computer with the USB-C data cable. Plug it in directly, not through a USB hub. (A cable that only charges will not work - see "Something not working?" below.)

  2. 2

    Connect

    Click Connect. A small window opens with a list of ports. Choose "USB JTAG/serial debug unit" (on Windows it is called "USB Serial Device (COM3)" - the number may differ) and click Connect in that window.

  3. 3

    Install

    Click Install firmware and wait until the bar is full. This takes about a minute. Installing puts the flashlight's saved settings (for example a custom profile) back to the factory defaults.

    Technical details:

    Something not working?

    No port appears in the list
    The cable is the usual reason: many USB-C cables only charge and have no data wires. Try a different cable (the one of a phone or laptop is often fine), then a different USB port on the computer, plugged in directly. Still empty? (the list then contains every port, not only the flashlight's).
    The port is listed, but connecting fails
    Switch the flashlight to its built-in download mode by hand:
    1. Unplug the USB cable from the flashlight.
    2. Press and hold the round metal button on the flashlight (either small button works too).
    3. While holding it, plug the cable in.
    4. Let go of the button after about a second.
    5. Click Connect again.
    An error appears while installing
    Unplug the cable, plug it in again and start over at step 2. A failed installation cannot break the flashlight for good: its built-in download mode is always there, so you can simply try again.
    The port is busy or "access denied"
    Close other programs and browser tabs that may be using the flashlight (a serial monitor, the Arduino IDE, another copy of this page), then unplug and plug in again.
    The light stays dark after installing
    Unplug the cable, plug it in again and press the round metal button once. If it is still dark, let the flashlight charge for ten minutes and try again.
    Advanced: use a different .bin file

    Only if the developers gave you a firmware file. It must be one complete "merged" image for address 0x0 of an ESP32-C3 (bootloader, partition table and app in one file, like flashka-fw-v0.6.0-merged.bin). Installing the wrong file can leave the flashlight not starting - you could then repeat the installation with the right one.
